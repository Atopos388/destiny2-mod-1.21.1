# Changelog

Notable project changes are documented here. The project has not yet made a stable public release.

## Unreleased

### Added

- Three evolving subclass gameplay foundations and supporting ability systems.
- Custom weapons, armor, loot, UI, animation, rendering, and particle experiments.
- World pickup entities and Minecraft-style home-industry machine prototypes.
- Automated contract tests and a generated source dependency graph.
- Public contribution, security, issue, and pull-request guidance.

### Known limitations

- Experimental APIs, balance, and save formats may change.
- Multiplayer, compatibility, performance, and visual acceptance coverage is incomplete.
- Local third-party JAR provenance and redistribution terms require review before a public binary release.
