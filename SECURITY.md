# Security Policy

## Supported versions

The project has no stable release yet. Security fixes are currently applied to the latest `main` branch only.

## Reporting a vulnerability

Please do not publish exploit details in a normal issue. Use the repository's private vulnerability reporting page when it is available:

`https://github.com/Atopos388/destiny2-mod-1.21.1-backup/security/advisories/new`

If private reporting is unavailable, open a minimal issue asking the maintainer for a private contact channel without including vulnerability details.

Include the affected commit or version, reproduction conditions, expected impact, and any suggested mitigation. Reports will be acknowledged as maintainer capacity allows; this volunteer project does not currently promise a fixed response SLA.
