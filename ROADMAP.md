# Roadmap

This roadmap communicates direction, not a delivery guarantee. Priorities may change after testing and contributor feedback.

## Alpha foundations

- Stabilize server-authoritative ability state, cooldowns, energy, and networking.
- Bring the three subclass foundations to consistent data and test contracts.
- Refine grenade memory, world pickups, and shared gameplay primitives.
- Continue renderer and particle performance work across common hardware.
- Turn home-industry prototypes into a coherent power, processing, storage, and logistics loop.

## Public contributor readiness

- Audit every bundled or local JAR for provenance, license, and redistribution terms.
- Replace project-local dependencies with reproducible upstream coordinates or documented source builds where possible.
- Publish the first reviewed alpha with installation notes and known limitations.
- Add repeatable multiplayer, save migration, compatibility, and performance test scenarios.
- Label approachable issues and document extension points for abilities, effects, machines, and data tables.

## Later exploration

- Expand content only after shared foundations are stable.
- Improve accessibility and input remapping.
- Add profiling budgets and visual regression references for complex VFX.
- Evaluate supported extension APIs for third-party content packs without exposing unstable internals.
